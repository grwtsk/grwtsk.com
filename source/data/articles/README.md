# Articles

Each published letter has a stable slug directory containing `article.md`, `status.md`, `in/` (actual received responses) and `out/` (public-safe unsent email drafts). The static site reads `in/` but never `out/`; a draft is not a send. Article-specific research references and context belong with that letter. Shared organization and evidence data live in sibling directories under `source/data/`. See the [data guide](../README.md) for the article format and data layout.
