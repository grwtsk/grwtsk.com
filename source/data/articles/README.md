# Articles

Each published letter has a stable slug directory containing `article.md`, `status.md`, `in/` (actual received responses) and `out/` (public-safe unsent email drafts). The static site reads `in/` but never `out/`; a draft is not a send. Keep only these four entries in each article directory. Article-specific outreach research and context belong in [../outreach/](../outreach/README.md), grouped by the same slug. Shared organization and evidence data live in sibling directories under `source/data/`. See the [data guide](../README.md) for the article format and data layout.
