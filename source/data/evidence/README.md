# Evidence data

[Professional evidence](professional-evidence.json) and [historical evidence](historical-evidence.json) are reusable public-source records, not recipient lists. Preserve their provenance, classifications and limitations. Article-specific identity matches and case caveats remain in the [article-specific outreach manifests](../outreach/README.md). See the [data guide](../README.md).

[Research references](research-references.json) contains original public source metadata, directory references, and historical-only observations that are not addressees. Source-set names are provenance identifiers, not filenames. All contact and role data reside in the unified taxonomy. Evidence does not establish recipient eligibility or culpability.
